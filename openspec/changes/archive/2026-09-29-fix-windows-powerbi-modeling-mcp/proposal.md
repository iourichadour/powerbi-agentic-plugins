## Why

The Power BI Modeling MCP registration generated by setup fails on Windows before the MCP `initialize` response because the package's `npx` bootstrap tries to execute the extensionless `npm` command. The setup workflow currently reports MCP configuration as ready without validating this platform-specific launch path.

## What Changes

- Make the Power BI Modeling MCP source registration use a supported, pinned package invocation without the obsolete `--start` argument.
- Make `powerbi-modeling-mcp` the canonical server identity and recognize `powerbi-modeling` as a legacy alias during migration and conflict checks.
- Add Windows-aware registration for both Codex and Copilot so each harness uses the published Windows x64 package directly, avoiding the broken runtime auto-install path.
- Add setup validation and tests for the generated MCP command and stale duplicate server handling guidance.
- Detect and safely report conflicting profile-level Copilot MCP definitions in both `mcp.json` and `mcp-config.json`.
- Compare MCP definitions by transport and launch signature so a valid hosted HTTP registration is distinguished from the local Windows stdio registration with the same canonical name.
- Document that MCP registration and package provisioning are separate setup responsibilities and report actionable remediation when activation cannot be verified.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `codex-plugin-compatibility`: MCP registration must preserve the Power BI Modeling capability while applying a supported Windows host-specific command equivalent for Codex and Copilot.
- `codex-team-setup`: setup must generate, install, and validate an activatable Power BI Modeling MCP configuration rather than only copying its declaration.

## Impact

- `plugins/powerbi/.mcp.json`
- `setup-team-plugins.ps1` and setup validation/tests
- Codex MCP configuration generated under `%USERPROFILE%\\.codex\\config.toml`
- Copilot plugin files installed under `%USERPROFILE%\\.copilot`, including the projected `.mcp.json`
- Copilot profile MCP files under `%USERPROFILE%\\.copilot\\mcp.json` and `%USERPROFILE%\\.copilot\\mcp-config.json`
- Setup and developer documentation
